# Machine Learning Projects 🚀

This repository contains six machine learning projects implemented using Python and Google Colab.  
These projects helped me understand core ML concepts through hands-on practice.

## 📌 Projects Included

1. **Exploratory Data Analysis (EDA)**
   - Data cleaning, visualization, and insights

2. **Linear Regression**
   - Predicting continuous values
   - Model evaluation using error metrics

3. **Decision Tree**
   - Rule-based classification model
   - Easy to interpret and visualize

4. **Support Vector Machine (SVM)**
   - Classification using hyperplanes
   - Works well for complex datasets

5. **Hierarchical Clustering**
   - Unsupervised learning
   - Dendrogram-based clustering

6. **K-Nearest Neighbors (KNN)**
   - Distance-based classification
   - Simple and effective algorithm

## 🛠 Tools & Technologies
- Python
- Google Colab
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 📂 How to Run
Open the `.ipynb` files using:
- Google Colab or
- Jupyter Notebook
